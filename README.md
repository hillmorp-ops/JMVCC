<p align="center"><b>Мини-игры для JustMC — текстом.</b></p>

JMVCC — компилятор JustCode (`.jc`) в модули кода сервера JustMC (Creative+), мод-мост JMVCC Bridge и
инструменты для людей и LLM-агентов: подсказки к ошибкам, оптимизатор `-O`, заливка в мир одной командой,
мягкая остановка мира, RPC для агента.

📖 **Документация:** https://hillmorp-ops.github.io/JMVCC/
🤖 **Для агентов:** https://hillmorp-ops.github.io/JMVCC/llms.txt

Исходный код пока не опубликован — здесь сайт документации (ветка `gh-pages`).
