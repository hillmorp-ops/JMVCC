Установка и первый мир ​

За 10 минут: ставим компилятор, пишем первый .jc, заливаем его в свой мир на JustMC. Сначала руками, потом одной командой через мод.

1. Компилятор (CLI) ​

Исходники пока закрыты

Код компилятора и мода сейчас в приватном репозитории — сборки выдаёт автор. Публичные релизы появятся в hillmorp-ops/JMVCC. Ниже — сборка из исходников, когда доступ есть.

Нужны Node.js 18+, Yarn (npm install -g yarn), Git и Java: генератор парсера ANTLR (antlr4ts) запускается на Java.

bash
git clone https://github.com/hillmorp-ops/JMVCC.git
cd JMVCC
yarn install
yarn build            # грамматика ANTLR + TypeScript → dist/

На Windows собирай из Git Bash: скрипт сборки чистит папку командой rm -rf.

Проверь, что всё собралось:

powershell
.\jmvcc.cmd --version
bash
./jmvcc --version

Чтобы писать просто jmvcc из любой папки, добавь папку репозитория в PATH: в ней лежат запускалки jmvcc.cmd (Windows) и jmvcc (sh).

Один exe без Node

На Windows можно собрать самостоятельный jmvcc-win.exe, около 47 МБ, Node для него не нужен:

bash
npx pkg . -t node18-win-x64 --output jmvcc-win.exe

Старое имя

jmcc, jmcc.cmd и ./jmcc остались псевдонимами: это та же программа, что jmvcc.

2. Первый .jc ​

Создай папку под игру (не внутри репозитория) и в ней файл hello.jc:

jc
event<player_join> {
  player::title("&6Привет, %player%!", "&7Первый мир на JMVCC", 10, 60, 20)
  player::play_sound(sound("entity.player.levelup"))
  player::give_item(item("diamond"), 1)
}

Каждому, кто зашёл в мир, на экране покажется заголовок, прозвучит звук и выдастся алмаз. %player% сервер заменит на ник игрока, &6 и &7 задают цвет текста. Подробнее — в Синтаксисе и Тексте и интерфейсе.

Сначала проверка, потом компиляция:

bash
jmvcc check hello.jc      # все ошибки и предупреждения сразу, JSON не пишет
jmvcc compile hello.jc    # → hello.json рядом
jmvcc trace hello.jc      # во что превратился код: события и блоки

trace покажет:

text
event<player_join> 3 блоков:
  player_send_title(title="&6Привет, %player%!", subtitle="&7Первый мир на JMVCC", fade_in=10, stay=60, fade_out=20)
  player_play_sound(sound=sound(entity.player.levelup, 1, 1))
  player_give_items(items=[item(diamond)], amount=1)

Как читать ошибку компилятора ​

Опечатка player::mesage вместо player::message даёт:

text
 В файле hello.jc:2:10

 2    player::mesage("Привет, %player%!")
 ~            ~~~~~~

 Ошибка  У 'player' нет действия или значения 'player::mesage'. Возможно: message. Сигнатура: player::message(messages: text[18], merging: SPACES|CONCATENATION|SEPARATE_LINES)

Тут есть файл, строка и столбец, место ошибки подчёркнуто, а в «Возможно: …» стоит подсказка, которую обычно можно взять как есть. Сигнатура показывает, какие аргументы ждёт действие. Не знаешь, как называется нужное действие? Поищи:

bash
jmvcc search give potion        # поиск по словам
jmvcc sig player::title         # сигнатура и описание

Всё остальное — на странице Команды CLI и в Справочнике.

3. Залить вручную ​

bash
jmvcc compile -u hello.jc

Компилятор загрузит модуль на хостинг m.justmc.ru и напечатает команду:

text
 /module loadUrl force https://m.justmc.ru/api/…

Зайди в свой мир на сервере JustMC, перейди в режим кода /dev, вставь эту команду в чат и запусти мир /play.

Ссылка живёт 3 минуты

Успей выполнить команду, иначе загрузи заново. И помни: loadUrl force заменяет весь код мира модулем. Сервер иногда спрашивает это книжкой «ПРИНЯТЬ / ОТКАЗ».

Копировать ссылку при каждой правке надоест быстро, поэтому дальше ставим мод.

4. Мод JMVCC Bridge ​

Это клиентский мод Fabric. С ним CLI сам заливает модуль, запускает мир и читает ошибки сервера из чата.

ЧтоВерсия
Minecraft26.2
Fabric Loader0.20.1+
Fabric API0.161.0+26.2
Java для игры и сборки25

Готового .jar пока нет, мод собирается из client-mod/ в репозитории. Нужен JDK 25:

bash
cd client-mod
JAVA_HOME=/путь/к/jdk25 ./gradlew build
powershell
cd client-mod
$env:JAVA_HOME='C:\путь\к\jdk25'; .\gradlew.bat build

Получится client-mod/build/libs/jmvcc_bridge-0.1.0.jar. Положи его в папку mods клиента рядом с Fabric API и запусти игру.

При старте мод поднимает HTTP только на 127.0.0.1 и пишет порт и токен в ~/.jmvcc/bridge.json, на Windows это %USERPROFILE%\.jmvcc\bridge.json. CLI находит его сам, настраивать ничего не нужно. Зайди на сервер, в свой мир, и проверь:

bash
jmvcc client status

Должно быть игрок: … на … и управление: включено.

Агент под присмотром

Пока CLI управляет клиентом, в углу экрана висит плашка «🤖 JMVCC: управляет агент», а перед действием на секунду показывается title. Запретить управление — /j remote off в чате игры, разрешить снова — /j remote on. Подробно — на странице Мод JMVCC Bridge.

5. Деплой одной командой ​

bash
jmvcc client deploy hello.jc

Команда выполняет всю цепочку: компиляция → загрузка → /build → /dev → /module loadUrl force … → /play. Потом 5 секунд ждёт и печатает, что код написал в новой сессии. Вывод примерно такой:

text
✔ компиляция: hello.jc
✔ загрузка: https://m.justmc.ru/api/…
деплой: build ✔ 1.6 с · dev ✔ 2.3 с · module ✔ 1.1 с · play ✔ 4.1 с
сессия 2026-11-02_19-01-50:
событий нет
итог: ok, событий 0

При ошибке в логах или неудачном шаге команда возвращает код выхода 1, это удобно в скриптах и для агентов. Опции (-O, --no-play, --wait, --graceful) — в Командах CLI.

6. Ошибки и log(...) из игры ​

Компилятор ловит не всё: часть ошибок видит только сервер, когда код уже работает. Мод перехватывает их из чата, а log(...) — твой отладочный вывод:

jc
game var joins = 0

event<player_join> {
  joins += 1
  log("вошёл %player%, входов с запуска: $joins")
  player::title("&6Привет, %player%!", "&7Первый мир на JMVCC", 10, 60, 20)
  player::play_sound(sound("entity.player.levelup"))
  player::give_item(item("diamond"), 1)
}

Залей и перезайди в мир, потом читай:

bash
jmvcc client logs            # текущая сессия: ошибки, log(...), сообщения модуля (без чата)
jmvcc client logs --errors   # только ошибки и предупреждения
jmvcc client logs --since 42 # только новое (внизу вывода — последний seq)

Строка ошибки сервера выглядит так: #17 19:01:52 error <действие>: <причина> @ x y z. Здесь x y z — координаты блока кода в мире разработки. Исправь код, залей снова, прочитай логи. Это весь цикл.

log(...) видят все

Строки log уходят в чат всем игрокам мира, только с невидимой меткой для мода. Когда код заработал, убери их.
