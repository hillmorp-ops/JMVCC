select:: — выборка целей ​

34 действия объекта select::. Формат сигнатур — как у jmvcc sig: type[N] — список до N значений, A|B — перечисление (по умолчанию — первое), =X — что подставится, если не передать.

Проверь в терминале

Полное описание с перечислениями целиком: jmvcc sig select::<имя> --full. Поиск по смыслу: jmvcc search <слова>.
