variable:: — переменные ​

365 действий объекта variable::. Формат сигнатур — как у jmvcc sig: type[N] — список до N значений, A|B — перечисление (по умолчанию — первое), =X — что подставится, если не передать.

Проверь в терминале

Полное описание с перечислениями целиком: jmvcc sig variable::<имя> --full. Поиск по смыслу: jmvcc search <слова>.

Условия ​

Пишутся в if (...) { }, можно комбинировать через &&, ||, !.
