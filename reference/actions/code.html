code:: — управление кодом ​

17 действий объекта code::. Формат сигнатур — как у jmvcc sig: type[N] — список до N значений, A|B — перечисление (по умолчанию — первое), =X — что подставится, если не передать.

Проверь в терминале

Полное описание с перечислениями целиком: jmvcc sig code::<имя> --full. Поиск по смыслу: jmvcc search <слова>.

Блоки и циклы ​

Принимают тело в { }; у циклов — переменные цикла { x -> }.

code::controller_async_run ​

jcsig
code::controller_async_run()

Запуск в отдельном потоке (Run On Separate Thread) — Запускает код внутри поршней в отдельном потоке, что может уменьшить нагрузку. Отмена и возврат события не будут работать после поршней.

  • Некоторые действия внутри поршней могут не работать.

id: controller_async_run

code::do_not_run ​

на сервере: controller_do_not_run (тоже работает)

jcsig
code::do_not_run()

Игнорировать выполнение (Ignore Execution) — Игнорирует код, находящийся внутри скобок, во время выполнения.

id: controller_do_not_run

code::catch_error ​

на сервере: controller_exception (тоже работает)

jcsig
code::catch_error(variable: variable)

Уловить ошибку (Catch Error) — Улавливает ошибку в коде внутри поршней и присваивает её идентификатор к переменной (пример: function_not_found).

  • Не улавливает глобальные и критические ошибки.

id: controller_exception

code::isolated_selection ​

на сервере: controller_isolated_selection (тоже работает)

jcsig
code::isolated_selection(selection_mode: DEFAULT|CURRENT|EMPTY|FOR_EACH)

Изолировать выборку (Isolate Selection) — Изолирует выборку внутри скобок.

  • Созданная внутри выборка будет активна лишь в рамках скобок.
  • При выбранном типе выборки "Проход по выборке", внутри скобок может быть вызвано действие "Возврат" для перехода к следующему значению в выборке.

id: controller_isolated_selection

code::label ​

на сервере: controller_label (тоже работает)

jcsig
code::label(label: text)

Пометить код (Label Code) — Помечает код между поршнями указанным именем и позволяет его прервать.

  • Работает в связке с действием "Выйти из блока с меткой"

id: controller_label

code::measure_time ​

на сервере: controller_measure_time (тоже работает)

jcsig
code::measure_time(variable: variable, duration: NANOSECONDS|MICROSECONDS|MILLISECONDS)

Замерить время выполнения (Measure Execution Time) — Замеряет время выполнения кода внутри поршней и присваивает результат к переменной.

  • Учитывает блоки "Ждать".

id: controller_measure_time

code::call_function ​

jcsig
code::call_function(function_name: text, args: variable)

Вызвать функцию (Call Function) — Вызывает строку кода функции.

id: call_function

code::break_label ​

jcsig
code::break_label(label: text)

Выйти из блока с меткой (Break From Labeled Block) — Прерывает код, помеченный указанным именем.

Работает с: Действием "Пометить код".

id: control_break_label

code::throw_error ​

на сервере: call_exception (тоже работает)

jcsig
code::throw_error(id: text, message: text, type: WARNING|ERROR|FATAL)

Вызвать ошибку (Call Error) — Вызывает определённую ошибку с указанным ID и сообщением.

  • Рекомендуется использовать это в действии "Уловить ошибку".

id: control_call_exception

code::end_thread ​

на сервере: break (тоже работает)

jcsig
code::end_thread()

Остановить последовательность (Stop Sequence) — Останавливает текущую последовательность блоков кода. Любой код после этого блока не будет выполнен.

  • Если действие было использовано в функциях, то остановит родительскую строку, в которой вызвали функцию.

id: control_end_thread

code::return_function ​

jcsig
code::return_function()

Вернуться до вызова (Return From Function) — Останавливает текущую последовательность блоков кода в функции и возвращает к блоку вызова этой самой функции.

  • Возвращает до блока вызова текущей функции в родительской строке.

id: control_return_function

code::skip_iteration ​

jcsig
code::skip_iteration()

Пропустить повторение (Skip Iteration) — Пропускает одну итерацию в текущем повторении.

Работает с: Повторениями.

id: control_skip_iteration

code::stop_repeat ​

jcsig
code::stop_repeat()

Остановить повторение (Stop Repeat) — Полностью останавливает текущее повторение.

Работает с: Повторениями.

id: control_stop_repeat

code::wait ​

jcsig
code::wait(duration: number, time_unit: TICKS|SECONDS|MINUTES)

Ждать (Wait) — Приостанавливает текущую последовательность блоков кода на определённое время.

  • Минимальная задержка - 1 тик; в режиме Тики можно установить только целые числа.

id: control_wait
