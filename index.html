Код вместо блоков

Пишешь event, function, if и переменные в обычном редакторе — компилятор собирает из них строки блоков сервера.

💡

Компилятор, который учит

Ошибки с «Возможно: …» и ожидаемой сигнатурой, check — все ошибки сразу, предупреждения о тихих ловушках сервера.

⚡

Оптимизатор -O

Меньше блоков, а сервер выполняет столько же действий или меньше — проверено эталонным интерпретатором.

🔌

Мост в игру

Мод JMVCC Bridge и jmvcc client — деплой одной командой, ошибки и log(...) сервера прямо в терминал.

Зачем JMVCC ​

В JustMC (режим Creative+) код мира собирают из блоков. Пока это пара событий, блоки удобны. Но мини-игра с раундами, топами и меню — это сотни блоков, и тогда текст выигрывает:

  • Код в файле. Его можно читать, искать, копировать и хранить в git. Поправить механику — одна строка, а не перестройка блоков.
  • Ошибки до запуска. Компилятор знает все действия сервера, подсказывает «Возможно: …» и предупреждает о ловушках, которые на сервере ломают код молча.
  • Быстрый цикл. jmvcc client deploy заливает код в мир и сразу показывает ошибки сервера. Не надо копировать ссылки и листать чат.
  • ИИ-агенты. Claude Code и другие агенты пишут .jc с первого раза: для них есть llms.txt, скилл и мост в игру.

JMVCC — форк компилятора jmcc (rqbik и контрибьюторы). Код, написанный для jmcc, обычно подходит как есть. Чем они отличаются — на странице jmcc и JMVCC.

Как это выглядит ​

jc
save var %player%_coins

event<player_join> {
  %player%_coins ??= 0
  player::message("Монет: ${%player%_coins}")
}

event<player_break_block> {
  var roll = variable::random_in_range(1, 100)
  if (roll <= 25) {
    player::give_items(item("diamond"), 1)
    %player%_coins += 5
  }
}

Монеты сохраняются у каждого игрока отдельно (save var %player%_coins). Сломал блок — с шансом 25% получаешь алмаз и 5 монет.

Быстрый старт в 3 шага ​

1. Собери компилятор. Нужны Node.js 18+, Yarn и Java:

bash
git clone https://github.com/hillmorp-ops/JMVCC.git
cd JMVCC && yarn install && yarn build

2. Поставь мод. Собери client-mod/ (JDK 25) и положи jmvcc_bridge-0.1.0.jar в mods клиента Fabric для Minecraft 26.2. Зайди в свой мир на JustMC.

3. Залей код.

bash
jmvcc client deploy game.jc   # компиляция → загрузка → /module loadUrl → /play → ошибки сервера

Без мода тоже можно: jmvcc compile -u game.jc напечатает команду /module loadUrl force …, её надо вставить в чат игры. Подробно, с первым .jc, — в Установке.
